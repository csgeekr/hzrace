# Hangzhou Event Calendar

参考https://csgeekr.com/的设计风格，设计一个网页名称为杭城赛事。以年度日历的形式列出每年杭州定期举办的赛事活动。支持在线新增和删除，纯前端架构。赛事信息如下：5月

GAITC 全球人工智能技术大会（中国人工智能学会主办）—— 2026年5月23-24日在杭州举行，是国内AI领域千人级综合性活动 Caai

之江杯全球人工智能大赛 —— 每年5-6月启动报名，7-8月初赛复赛，9-10月举办全球总决赛，是浙江省政府牵头的AI赛事品牌
